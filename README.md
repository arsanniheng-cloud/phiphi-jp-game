# จป.ซัน แห่งเกาะพีพี

เกมจำลองงาน **จป.วิชาชีพ** (เจ้าหน้าที่ความปลอดภัยในการทำงาน) ในรีสอร์ตริมอ่าวบนเกาะพีพี

- พนักงาน 204 คน 12 แผนก ทุกคนมีชื่อ นิสัย เรื่องราว และ **จำได้** ว่าคุณเคยทำอะไรกับเขา
- เดินตรวจหาจุดเสี่ยง ตัดสินใจ (หยุดงาน / คุยสอน / ออก CAR) พิจารณาใบอนุญาตทำงาน (PTW) และสอบสวนอุบัติเหตุ
- ไฮซีซันแขกเต็ม · โลว์ซีซันมรสุมและงานซ่อมบำรุง · กลางวัน/กลางคืน
- เล่นคนเดียว, หลายคนในเครื่องเดียว (2–4 คน) หรือ **ออนไลน์ต่างเครื่อง** ด้วยรหัสห้อง
- อาคาร ต้นไม้ และเรือ เรนเดอร์เป็นภาพ 3 มิติด้วย Blender

**เล่นได้ทันทีในเบราว์เซอร์** ทั้งคอมและมือถือ — เปิด `index.html` หรือลิงก์ GitHub Pages ของ repository นี้

คู่มือ โครงสร้างไฟล์ ฐานข้อมูล และความปลอดภัย: [docs/README.md](docs/README.md)
